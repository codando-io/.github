# Codando

Codando Software builds its own products in Brazil: small, careful software that
does one job and shows its sources. [codando.io](https://codando.io)

## Products

**[Prumo](https://src.capivaras.dev/scriptorium/prumo)** · *De onde veio e para
onde foi o dinheiro das campanhas eleitorais no Brasil.*
A civic-transparency explorer for the campaign-finance data published by the
Brazilian Superior Electoral Court (TSE): candidate profiles, money flows, donors
and suppliers, a relationship graph, and a change log, covering the 2018, 2022,
and 2026 elections. Every number traces back to its public source, and the
analysis stays descriptive and politically neutral.

**Lastro** · personal and business finance in one place, self-hosted.
In development.

## Open source

**[Officina](https://src.capivaras.dev/scriptorium/officina)** · the engineering
process we build with, packaged so any project can adopt it:
investigate before changing code, small reversible changes, tests as evidence,
review of the real diff, and observability after every deploy.

Coming next, being prepared for release:

- **Depot** · streaming blob storage for .NET, one small API over the file
  system, memory, S3, Azure Blob Storage, and relational databases.
- **CaptchaKit** · one way to integrate CAPTCHA in .NET and Angular, with the
  vendor as a configuration value instead of an architectural commitment.

## How we work

Evidence before assumptions. Small changes that are easy to revert. Every
decision that is hard to undo gets written down.
